# ASCEND V2 — воспроизводимый сравнительный исторический прогон

## Назначение

Отдельный исследовательский контур, без изменений боевой логики, Cloudflare-продукции, Telegram-сигналов и ордеров. Используются **реальные Binance USDⓈ-M Futures** 1-минутные свечи и пятиминутный OI; это **не** история MEXC.

## Источники данных

- `research/data/binance_BTCUSDT_20261006_20261010.json`
- `research/data/binance_ETHUSDT_20261006_20261010.json`
- `research/data/binance_SOLUSDT_20261006_20261010.json`

Каждый файл: 7200 последовательных 1m OHLCV с полем `taker_buy_base_volume`, 1440 исторических точек OI в исходных единицах биржи. Получено из подключённого Binance Futures API, без заполнения пропусков синтетическими барами.

Данные 6 октября: прогрев и формирование замороженных уровней YH/YL. In-sample: **07.10.2026 00:00 UTC — 09.10.2026 00:00 UTC**. Out-of-sample: **09.10.2026 00:00 UTC — 11.10.2026 00:00 UTC**. Один непрерывный календарный split для всех монет, фиксируется заранее. Не является разделением 30/13 прежнего 43-сигнального набора (его первичных записей нет в доступных вложениях).

## Поведение стратегий

`BASE_V2`: неизменённый `confirmation-engine-v2.js` с расчётом CHOCH из `choch-10m.js` и MTF-контекста из `structure-evidence.js`. Замороженные уровни **только** максимум/минимум предшествующего полного дня по UTC; они известны лишь с начала нового дня. Реконструкция прочих ONH/ONL/RTH/IBL и полных UI Core RSI/VWAP/Session-гейтов **не заявляется**. Это исследование **структурного V2**, не полноценный `ENTRY READY` production.

`V2_FVG`: тот же V2 плюс известный до ретеста 3m FVG по трём **полностью закрытым** свечам, в направлении сделки, размер 0.25–1.00 × 3m ATR(14), с повторным касанием зоны свечой ретеста.

`V2_CVD_OI`: V2 плюс направленный дисбаланс последних 15 **закрытых** 1m свечей из точного Binance 1m `taker_buy_base_volume` (`2 × takerBuy - totalVolume`), и **рост** OI за 15 минут; снимки OI консервативно считаются известными через 5 минут после отметки биржи. Дельта — минутные агрегаты, не сохранённый тиковый поток сделок. Этот фильтр — заранее заданная гипотеза, а не проверенная интерпретация OI.

`V2_BOOK_LIQ`: помечен `NO_DATA`, **статистика и WR не рассчитываются**: исторического синхронного потока изменения стакана и фактических ликвидаций за эти даты нет. Текущий снимок стакана нельзя применять к прошлым решениям.

## Исполнение и строгость

- Стратегические решения принимаются строго на закрытии свечи по данным, доступным на её закрытии. Никаких будущих pivot/FVG/OI.
- Вход на `open` **следующей** минутной свечи с неблагоприятным slippage **0.03%**.
- Комиссия taker **0.06% на сторону**, выходное slippage **0.03%**: это консервативные модельные гипотезы, а не подтверждённые VIP-тарифы пользователя.
- `R:R` перепроверяется по фактической моделируемой цене входа, минимум **2.0**.
- Structural SL / следующая замороженная цель — строго из V2; внутриминутное касание SL и TP одной свечой трактуется в пользу SL (консервативно).
- Позиция закрывается по SL, TP либо **12 часам**; на границе split — принудительное закрытие, без протекания train в test.
- Отдельная позиция на монету в каждой группе, без перекрывающихся входов. Результаты в `R` после комиссий и проскальзывания.
- Все неподтверждённые решения остаются WAIT; наблюдения без полного V2 не являются сделками.
- Данные строго одной биржи. Данные MEXC, Binance и Bybit не взаимозаменяемы.

## Как повторить

```bash
node --check research/compare_v2.mjs
node research/compare_v2.mjs
```

Результат: `research/comparative_v2_results_20261012.json`. Отдельный GitHub Actions workflow `ASCEND Comparative V2 Historical Research` запускает эту команду и сохраняет JSON артефактом.

## Ограничения

Малый временной диапазон и низкая частота последовательных V2-подтверждений могут дать 0 сделок. Это честный статистический результат на этом наборе, а не основание автоматически ослаблять критерии. Для оценки прибыли и устойчивости нужны месяцы фактической MEXC-истории плюс архив потока Market Participation, отложенные OOS-периоды, fee/funding и реалистичная оценка fill probability.
