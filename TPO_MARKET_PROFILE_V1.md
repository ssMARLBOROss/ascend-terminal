# ASCEND · отдельный TPO Market Profile

Страница: **`/?view=tpo`**, пункт меню «▦ TPO · Профиль» (включая мобильное меню).

## Назначение
Воспроизвести тип анализа с пользовательского скриншота от 19 октября 2026: TPO-буквы по ценам и времени, POC, VAH, VAL, возможный NPOC, сессии Asia / Frankfurt / London / New York. Не накладывается на центральный свечной график и не заменяет ASCEND Structure Engine.

## Источник
- Только реальные MEXC Futures USDT 5m свечи с терминального `/api/v2/klines`; запрашиваем максимум 700, при сбое используем текущий 5m буфер только для того же выбранного символа.
- Интервалы TPO: 15/30/60 минут. Буква формируется только когда **все** закрытые 5m свечи соответствующего окна доступны. Нет интерполяции пропусков.
- Каждый период даёт +1 TPO на каждом ценовом шаге, пройденном между его High и Low; это **приближение по 5m OHLC**, не тиковый TPO и не Volume Profile (не взвешиваем объёмом).
- POC = цена с максимальным числом TPO. Value Area = расширение соседними уровнями по убыванию числа TPO до 68/70/72%, по умолчанию 70%.
- NPOC предыдущего UTC дня показываем только при полной предыдущей истории, если последующие свечи его не тестировали; в остальных случаях «Нет данных».

## Сессии UTC
- Азия: 00:00–08:00
- Франкфурт: 06:00–09:00
- Лондон: 07:00–16:00
- Нью-Йорк: 13:00–22:00

Интервалы пересекаются, поэтому каждый сессионный профиль строится **независимо**, а общий профиль считает каждый временной период ровно один раз.

## Интерфейс
- Две даты: последний доступный UTC день и предыдущий.
- Переключатели длины букв (15/30/60m), ценового разрешения (36/48/72), Value Area (68/70/72%).
- Кликабельные строки дают цену, число TPO и время первого/последнего наблюдения.
- Цвета букв и карточки сессий, отметки POC/VAH/VAL/цены/NPOC, карточка источника и полноты данных.
- Когда истории не хватает, показываем PARTIAL/NO DATA, не фальсифицируем значения.

## Изоляция / ограничения
Исследовательская визуализация **не читает и не меняет** подтверждения сделки, CORE, ENTRY READY, Telegram, риск и ордера. Не экстраполирует будущие цены.
Тестировать командой `node --test tests/tpo-market-profile-v1.test.mjs`; дополнительно открыть новую страницу в desktop и mobile после проверки.
