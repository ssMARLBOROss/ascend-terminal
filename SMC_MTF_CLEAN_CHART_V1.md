# ASCEND · компактный SMC / FVG multi-TF · исследовательский слой

Ветка для ревью. Production не изменён.

## Выбранный вариант
- Центральный график: закрытые OHLCV, Volume под свечами, SMA 20/50/200, VWAP UTC.
- Замороженные ONH/ONL 00:00–06:00 UTC и YH/YL остаются в существующей Liquidity Map.
- SMC по кнопке «☷ Слои». Новые умолчания: FVG ON; таймфреймы 3m/5m/15m; ATR 14; направление обе стороны; по теням; минимальный размер 0,05%; ближе к цене; прозрачность 42%; максимум 4; только активные; середина 50%.
- Можно включить отдельно 1m и 30m, исторические зоны, выбор стороны, другую ATR и расчёт по закрытиям.
- По каждой зоне доступны фактическое время создания, первое касание, % заполнения и размер ATR при наличии данных.
- Другие POI: IFVG, OB, RB, STB/BTS, OTE — в отдельных выключенных по умолчанию слоях.
- **Связка FVG после MSS НЕ считается подтверждённой**, пока Structure Engine не предоставит проверенное событие. Поле показывает, что данных нет; не раскрашивает зоны вымышленными подтверждениями.
- Модули TPO, стакан, OI, CVD, Net Long/Short не подменяются имитацией; отсутствие источника обозначается NO DATA.

## Источник и причинность
FVG считается по последовательным полностью закрытым OHLC свечам выбранного TF, проверяется 3-свечное окно и ATR, а заполнение учитывает только свечи **после** образования зоны. Пропуски данных обрывают цепочку. Режим по закрытиям и по фитилям независимы. Замороженные уровни и действующая торговая цепочка сохраняются.

## Границы
Это визуальная аналитика. Существующие подтверждения, ENTRY READY, Telegram, риск и маршрутизация ордеров не меняются. FVG не является доказательством ордеров крупных участников и не гарантирует реакцию.
