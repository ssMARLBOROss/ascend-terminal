# ASCEND Terminal

Отдельный веб-интерфейс ASCEND. Торговая логика основного бота этим репозиторием не изменяется.

## V0.1
BTC Market State, Market Pressure, Reversal Risk, магниты, Decision Zone, четыре горизонта и цепочка SIGNAL₀ → MAGNET → SWEEP → SIGNAL₁ → REACTION → BOS/CHOCH → RETEST → SL/TP → ENTER.

Неподключённые реальные источники отображаются как NOT CONNECTED — без выдуманных рыночных данных.
